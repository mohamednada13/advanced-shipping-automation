# 🚢 Advanced Freight Scraper & Cloud Automation Engine v3.0 ✈️

A professional-grade logistics automation system deployed on **Arch Linux** and adapted for **Cloud-SaaS** via **GitHub Actions**.

## 🌟 Key Features
- **Geographical Intelligence:** Automatically detects whether codes are Air (IATA 3-letter) or Ocean (UN/LOCODE 5-letter) and routes pricing logic realistically.
- **Dynamic Cloud UI:** Fully optimized for mobile execution through GitHub Actions input panel—allowing rate checking from anywhere via phone.
- **Decoupled Architecture:** Modular split featuring standalone email modules and scalable freight calculations.

## 🛠️ Tech Stack
- Python 3, Playwright, Pandas, Openpyxl, GitHub Actions
